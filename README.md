# Initial Software Product/Solution Demonstration  
### Blockchain Attendance System (Low-Level Track)

---

## **Project Description**
The **Blockchain Attendance System** is a prototype that replaces manual attendance tracking with a **blockchain-powered solution**.  
It ensures transparency, immutability, and reliability by leveraging **smart contracts** on the Ethereum blockchain.  

Traditional attendance systems can be easily manipulated or lost. This system securely records attendance data that **cannot be altered**, creating trust and accountability for educational institutions.

This project is developed as part of the **Low-Level Track** for the **Initial Software Product/Solution Demonstration** assignment.

---

## **Core Features**
✅ Secure MetaMask wallet login  
✅ Smart contract for attendance data storage  
✅ Add and verify attendance on blockchain  
✅ Simple HTML/CSS/JS user interface  
✅ Local and online deployment support

## **System Overview**
1. **User Interface (Frontend):**
   - HTML/CSS/JavaScript interface for admin and users.
   - Connects MetaMask for authentication and blockchain transactions.

2. **Smart Contract (Backend):**
   - Written in Solidity.
   - Handles storing and verifying attendance records on Ethereum.

3. **Blockchain Network:**
   - Uses a decentralized ledger (Ganache or Sepolia Testnet) to store immutable attendance data.

4. **Integration Layer:**
   - Uses **Web3.js** to bridge frontend and blockchain.
